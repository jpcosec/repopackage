# T-09 - Wire CLI Commands to Domain Layer

## Traits (Composición)
`[Refactoring] | [CLI] | [Python] | [Ref: Typer, Workspace]`

## Explanation
Refactorizar los comandos existentes (`desk board sync`, `desk tasks atomize`, `desk pills inject`) para que sean thin shells del Domain Layer. Toda la lógica de negocio debe moverse a `src/repopackage/workflow/`. Los comandos CLI quedan en ≤10 líneas cada uno.

## Reference
- `desk/pills/PILL-11.md`
- `desk/pills/PILL-09.md`
- `src/repopackage/cli/desk/commands.py`
- `src/repopackage/workflow/workspace.py` (T-08)

## What to Fix / Implement
Reescribir `src/repopackage/cli/desk/commands.py`:

```python
# sync_board: antes ~15 líneas, después:
@board_app.command(name="sync")
def sync_board():
    Workspace().desk.board_sync()
    typer.echo("Board.md synchronized.")

# atomize_task: antes ~40 líneas, después:
@tasks_app.command(name="atomize")
def atomize_task(task_id: str):
    pills = Workspace().desk.tasks.atomize(task_id)
    for p in pills:
        typer.echo(f"Created: {p.id}")

# inject_pill: antes ~30 líneas, después:
@pills_app.command(name="inject")
def inject_pill(task_id: str = ..., pill_id: str = ...):
    Workspace().desk.pills.inject(task_id, pill_id)
    typer.echo(f"Injected {pill_id} into {task_id}.")
```

También registrar `Workspace` en `core.py`:
- Importar desde `repopackage.workflow`.
- Mantener routing existente (`desk_app`, `board_app`, `tasks_app`, `pills_app`).

## How to Do It (Suggested)
1. Reescribir `sync_board()` usando `Workspace().desk.board_sync()`.
2. Reescribir `atomize_task()` usando `Workspace().desk.tasks.atomize(task_id)`.
3. Reescribir `inject_pill()` usando `Workspace().desk.pills.inject(task_id, pill_id)`.
4. Eliminar imports directos de `MarkdownEngine`, `TaskParser`, `BoardWriter` del archivo de comandos.
5. Actualizar tests existentes si cambian las firmas.
