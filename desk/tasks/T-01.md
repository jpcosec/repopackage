# T-01 - Setup Core CLI Package

## Traits (Composición)
`[Implementación] | [CLI] | [Python] | [Ref: Typer]`

## Explanation
Configurar la estructura base del paquete `repopackage` y la clase base para los comandos. Debe soportar el routing jerárquico.

## Reference
- `desk/design/cli_class_diagram.puml`
- `desk/design/cli_structure.puml`

## What to Fix / Implement
- Archivo `cli.core` con el App principal de Typer.
- Clase `CommandBase` en `cli.command_types`.
- Scripts de entrada para ejecutar como `rp`.

## How to Do It (Suggested)
1. Crear el folder `src/repopackage/cli`.
2. Implementar `CommandBase` con métodos `configure` y `run`.
3. Configurar el routing inicial para la categoría `system`.
