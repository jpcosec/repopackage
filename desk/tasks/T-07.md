# T-07 - Fix IO Layer: Jinja2 Templates + stdlib Paths

## Traits (Composición)
`[Fix] | [CLI] | [Python] | [Ref: Jinja2, Pathlib]`

## Explanation
Corregir los problemas actuales de la capa IO antes de introducir el Domain Layer:
1. `board_writer.py` llama a `writer.write_board()` en `commands.py` pero el método real es `render_board()` → bug activo.
2. `BoardWriter.__init__` usa `FileSystemLoader(Path("src/repopackage/cli/templates"))` con path relativo al cwd → se rompe si el CLI se corre desde otro directorio.
3. `atomize_task` en `desk/commands.py` usa `template_path.read_text().replace("PILL-XX", pill_id)` para generar pills → debe usar Jinja2 + `pill.md.jinja2`.
4. Crear `task.md.jinja2` para poder renderizar tasks desde Pydantic models.

## Reference
- `desk/pills/PILL-10.md`
- `src/repopackage/cli/engines/board_writer.py`
- `src/repopackage/cli/desk/commands.py`
- `src/repopackage/cli/templates/pill.md.jinja2`

## What to Fix / Implement
1. En `board_writer.py`: cambiar `FileSystemLoader` para usar `Path(__file__).parent.parent / "templates"`.
2. En `desk/commands.py` función `sync_board`: cambiar `writer.write_board(content)` → `writer.render_board()`.
3. En `desk/commands.py` función `atomize_task`: usar Jinja2 para generar pills via `pill.md.jinja2` en vez de `.replace()`.
4. Crear `src/repopackage/cli/templates/task.md.jinja2` con el template de tarea.

## How to Do It (Suggested)
1. Fix `board_writer.py`: `TEMPLATES_DIR = Path(__file__).parent.parent / "templates"`.
2. Fix `sync_board` en `commands.py`: usar `writer.render_board()` y escribir resultado directamente.
3. Fix `atomize_task`: cargar env Jinja2 con path absoluto, usar `pill.md.jinja2`.
4. Crear `task.md.jinja2` espejando el template de `workflow/docs/template/task.md`.
