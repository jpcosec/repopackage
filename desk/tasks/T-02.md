# T-02 - Implement Markdown Integrity Engine

## Traits (Composición)
`[Implementación] | [Schema] | [Python] | [Ref: Regex]`

## Explanation
Crear el motor encargado de leer y escribir secciones en archivos Markdown sin alterar el resto del documento. Debe vincularse con Pydantic para validación.

## Reference
- `desk/pills/PILL-02.md`
- `desk/pills/PILL-03.md`

## What to Fix / Implement
- Clase `MarkdownEngine` capaz de extraer secciones por encabezado (##).
- Modelos Pydantic para `Task` y `Pill`.
- Validación de que los campos obligatorios existan.

## How to Do It (Suggested)
1. Usar regex `^##\s+(.*?)\n([\s\S]*?)(?=\n##|$)` para parsear secciones.
2. Implementar lógica de escritura que reemplace solo el bloque correspondiente.
