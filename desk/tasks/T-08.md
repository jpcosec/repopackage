## Explanation
Crear el paquete `src/repopackage/workflow/` que modela el workflow como objetos navegables con comportamiento. Este es el corazón del cambio arquitectónico: el CLI deja de implementar lógica y pasa a ser un reflejo de este Domain Layer.

El Domain Layer provee la API que tanto el CLI como el código externo pueden usar directamente:
```python
ws = Workspace()
ws.last_phase().eval()
ws.desk.tasks.atomize("T-07")
ws.drawers.list()
```

## What to Fix / Implement
Crear `src/repopackage/workflow/` con los siguientes módulos:

### `workspace.py` — `Workspace`
- `__init__(self, root: Path = None)`: root = `Path.cwd()` si no se provee.
- `@property desk` → `Desk(self)`
- `@property drawers` → `Drawers(self)`
- `phases() → List[Phase]`: lee tasks dir, agrupa por campo `phase` del TaskModel. Si todas tienen phase=None, retorna `[Phase("1", self)]`.
- `last_phase() → Phase`: última fase con tasks (la más alta, o la actual si hay open).
- `phase(id: str) → Phase`

### `phase.py` — `Phase`
- `__init__(self, id: str, workspace: Workspace)`
- `tasks() → List[WorkflowTask]`: tareas de esta fase.
- `eval() → EvalResult`: corre `pytest` en `tests/` usando `subprocess.run`, captura stdout/stderr, retorna `EvalResult(passed, failed, output)`.

### `desk.py` — `Desk`, `TaskCollection`, `PillCollection`
- `Desk(workspace)`:
  - `@property tasks → TaskCollection`
  - `@property pills → PillCollection`
  - `board_sync() → None`: lee tasks, renderiza board via `BoardWriter`, escribe `Board.md`.
- `TaskCollection(workspace)`:
  - `all() → List[WorkflowTask]`
  - `get(task_id: str) → WorkflowTask`
  - `atomize(task_id: str) → List[WorkflowPill]`: extrae checklist de "How to Do It", genera pills via Jinja2 (`pill.md.jinja2`), actualiza task file.
- `PillCollection(workspace)`:
  - `all() → List[WorkflowPill]`
  - `inject(task_id: str, pill_id: str) → None`

### `drawers.py` — `Drawers`, `DrawerSpec`
- `DrawerSpec(BaseModel)`: `id`, `title`, `domain`, `path: Path`, `status: str`
- `Drawers(workspace)`:
  - `list() → List[DrawerSpec]`: lee `drawers/Board.md` si existe, sino escanea `drawers/` por `.md`.
  - `add(spec_path: Path, title: str, domain: str) → DrawerSpec`: registra en `drawers/Board.md`.
  - `promote(spec_id: str) → WorkflowTask`: crea task skeleton en `desk/tasks/` desde spec.
  - `audit() → List[str]`: detecta specs sin title/domain.

### `task.py` — `WorkflowTask`
- `WorkflowTask(model: TaskModel, path: Path, workspace: Workspace)`
- `@property id`, `title`, `status`, `phase`, `pills`
- `save() → None`: escribe el `.md` via Jinja2 (`task.md.jinja2`).

### `pill.py` — `WorkflowPill`
- `WorkflowPill(model: PillModel, path: Path, workspace: Workspace)`
- `@property id`, `title`, `type`
- `save() → None`: escribe el `.md` via Jinja2 (`pill.md.jinja2`).

### `__init__.py`
- Exportar: `Workspace`, `Phase`, `Desk`, `Drawers`, `WorkflowTask`, `WorkflowPill`
