# ST-repo-dep: Google Repo tool dependency

**Basado en:** UC-06

## Script

```bash
# 1. Check if repo is installed
which repo
echo "Exit: $?"
repo --version 2>&1
echo "Exit: $?"

# 2. What does the manifest module import?
python3 -c "
from repopackage.repo.manifest import ManifestBuilder
import inspect
source = inspect.getsource(ManifestBuilder.sync)
# Check if repo tool is hardcoded
if 'repo' in source:
    print('ManifestBuilder.sync calls repo tool: YES')
    for i, line in enumerate(source.split(chr(10))):
        if 'repo' in line:
            print(f'  Line {i+1}: {line.strip()}')
else:
    print('ManifestBuilder.sync does NOT call repo tool directly')
"

# 3. Trace the actual subprocess call
python3 -c "
from repopackage.repo.manifest import ManifestBuilder
import inspect
# Look at _run_cmd
if hasattr(ManifestBuilder, '_run_cmd'):
    source = inspect.getsource(ManifestBuilder._run_cmd)
    print('_run_cmd source:')
    for line in source.split(chr(10)):
        print(f'  {line}')
"

# 4. Is repo tool required for non-sync commands?
echo "--- init ---"
rp init --help 2>/dev/null | head -1
echo "--- resolve ---"
rp resolve --help 2>/dev/null | head -1
echo "--- validate ---"
rp validate --help 2>/dev/null | head -1
echo "--- status ---"
rp status --help 2>/dev/null | head -1
echo "--- generate ---"
rp generate --help 2>/dev/null | head -1
echo "--- graph ---"
rp graph --help 2>/dev/null | head -1
echo "--- exports ---"
rp exports --help 2>/dev/null | head -1
echo "Exit: $?"

# 5. What happens if repo is missing? (dry check)
# The manifest module calls 'repo sync' via subprocess
# Without repo, we'd get FileNotFoundError
python3 -c "
import subprocess
try:
    result = subprocess.run(['repo', '--version'], capture_output=True, text=True, timeout=5)
    print(f'repo available: {result.returncode == 0}')
except FileNotFoundError:
    print('repo NOT available on PATH')
except Exception as e:
    print(f'repo check error: {type(e).__name__}: {e}')
"

# 6. Does repopackage vendor its own repo implementation or wrap the external tool?
python3 -c "
from repopackage.repo import manifest
import inspect
# Check if manifest.py has a vendored version or just wraps
manifest_source = inspect.getsource(manifest)
if 'subprocess' in manifest_source:
    print('Uses subprocess (external tool): YES')
if 'pygit2' in manifest_source:
    print('Uses pygit2 directly: YES')
if 'repo' in manifest_source:
    print('References repo tool: YES')
"

# 7. Can sync work without repo? (check for alternative path)
python3 -c "
from repopackage.git.client import GitClient
import inspect
gc_source = inspect.getsource(GitClient)
if 'repo' in gc_source.lower():
    print('GitClient references repo tool')
else:
    print('GitClient does NOT reference repo tool — uses pygit2 directly')
"

# 8. Check dependencies: is repo listed in requirements?
grep -i "repo" requirements.txt 2>/dev/null || echo "repo not in requirements.txt"
grep -i "repo" pyproject.toml 2>/dev/null || echo "repo not in pyproject.toml"

# 9. Check if Google Repo's manifest format is compatible
# The manifest.xml generated by ManifestBuilder
mkdir -p /tmp/rp-test-manifest
python3 -c "
from repopackage.repo.manifest import ManifestBuilder
import yaml

lock = yaml.safe_load(open('/home/jp/proyectos/hum-ecosystem/tools/repopackage/compose.lock.yaml'))
print('Lockfile loaded. Project:', lock.get('project'))
print('Number of packages:', len(lock.get('packages', {})))
print('Number of repopackages:', len(lock.get('repopackages', {})))
print('compatibility status:', lock.get('compatibility', {}).get('status'))
"

# 10. Does the project work without repo at all? (test non-sync commands)
cd /tmp && rp init --help > /dev/null 2>&1 && echo "init: OK (no repo needed)"
cd /tmp && rp validate --help > /dev/null 2>&1 && echo "validate: OK (no repo needed)"
cd /tmp && rp status --help > /dev/null 2>&1 && echo "status: OK (no repo needed)"
cd /tmp && rp generate --help > /dev/null 2>&1 && echo "generate: OK (no repo needed)"
cd /tmp && rp graph --help > /dev/null 2>&1 && echo "graph: OK (no repo needed)"
cd /tmp && rp exports --help > /dev/null 2>&1 && echo "exports: OK (no repo needed)"
```

## Modos de fracaso

- repo tool es dependencia no documentada
- Sin repo: sync falla con subprocess.FileNotFoundError (no mensaje claro)
- No hay fallback a pygit2 para sync
- manifest.xml no compatible con Google Repo
- repo version requerida no documentada
- Dependencia externa no listada en requirements.txt
- Solo sync depende de repo, pero no hay validación temprana
