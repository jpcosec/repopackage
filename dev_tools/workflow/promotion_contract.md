# Promotion Contract

## Purpose
- Define the transition from drawer material into executable tasks and pills.

## Base Promotion

```markdown
# PROMOTION-XXX - <title>

- Source Drawer Item: <id or path>
- Approved By: <agent or role>
- Promotion Reason:
  - <reason>
- Generated Tasks:
  - T-XXX
- Generated Pills:
  - PILL-XXX
- Remaining Ambiguities:
  - <ambiguity>
- Blockers:
  - <blocker>
```

## Rules
- Promotion cannot happen while critical ambiguity remains.
- Promotion must preserve traceability back to the drawer spec.
