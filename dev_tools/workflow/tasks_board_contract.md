# Tasks Board Contract

## Purpose
- Define the canonical structure of `desk/tasks/Board.md`.

## Required Sections
- Active
- Blocked
- Ready to Promote

## Active Columns
- ID
- Type
- Domain
- Task
- Priority
- Depends On
- Pills
- Phase

## Blocked Columns
- ID
- Type
- Domain
- Blocker
- Gate

## Ready to Promote Columns
- ID
- Type
- Domain
- Item

## Rules
- Board rows must reference real task or drawer artifacts.
- Status on the board must match status in the underlying task file.
