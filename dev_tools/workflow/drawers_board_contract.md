# Drawers Board Contract

## Purpose
- Define the canonical structure of `desk/drawers/Board.md`.

## Required Sections
- Deferred Items
- Specs In Drawers

## Deferred Item Columns
- ID
- Type
- Domain
- Item
- Status
- Last Reviewed

## Spec Columns
- ID
- Topic
- Source
- Promotion Gate

## Rules
- Drawer items are not executable tasks by default.
- Promotion gate must be explicit for every spec entry.
