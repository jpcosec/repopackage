# Integration Contract

## Purpose
- Define how evaluated work becomes durable project knowledge.

## Required Fields

```markdown
# INTEGRATION-XXX - <title>

- Source: <task|phase|drawer spec>
- Code Updated:
  - `path`
- Docs Updated:
  - `path`
- Design Updated:
  - `path`
- Pills Removed:
  - PILL-XXX
- Pills Retained:
  - PILL-XXX
- Commit Evidence:
  - `<message or hash>`
```

## Rules
- Integration must move durable knowledge into code, docs, or design.
- Stale pills should be removed during integration.
