# Workflow Contracts

> Canonical schemas for workflow data and execution artifacts.

## Purpose

- Make every workflow object explicit and validation-friendly.
- Separate contracts from role instructions and from deferred specs.
- Preserve reuse across agents, domains, and languages.

## Rule

- Instructions tell agents how to act.
- Contracts define what an artifact must contain.
- Specs explain the system and evolve intent.
