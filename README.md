# Repopackage

Project for Python tooling to extract Gemini/web conversation turns, extract structured artifacts, and prepare semantic-analysis workspaces.

## Development Workflow

- **Agent Guidance**: `AGENTS.md` — Primary instructions for AI agents.
- **Project Standards**: `STANDARDS.md` — Quality and architectural rules.
- **Active Tasks**: `desk/tasks/Board.md` — Current execution status.
- **Workflow Details**: `WORKFLOW.md` — Execution rituals and policies.

## Key Directories

- `dev_tools/talk_extractor`: Primary source code.
- `dev_tools/workflow`: Workflow data contracts.
- `desk/`: Task tracking and context pills.
- `Raw/`: Input files for extraction.
